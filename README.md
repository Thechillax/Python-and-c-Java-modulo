# Python-and-c-Java-modulo
the difference in remainder between phyton, C and Java written in C++

The calculation in remainders are different between languages such being C/C++ or Python. Today's lecture has taught me that Python's calculation is a more accurate approach to calculate a the value of a remainder as it cannot be less than '0'  or negative. What makes the languages difference is that C truncates the negative value towards '0' while Python rounds the negative value towards negative infinity.This repo is written in C++ to show the difference in the calculation.
